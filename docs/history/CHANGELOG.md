# История развития проекта (changelog)

Летопись изменений Arena Shooter — по итерациям, в хронологическом порядке
(**от старых к новым**, свежие записи внизу). Одна итерация = одна feature-ветка =
один PR (см. «Ветки и PR» в [`CLAUDE.md`](../../CLAUDE.md)).

- **Источник истины** — git-история (`git log`) и подробные отчёты по итерациям в
  [`CLAUDE.md`](../../CLAUDE.md) («Текущий статус»). Здесь — сжатый навигационный
  индекс: что, когда и в каком PR появилось. За деталями (алгоритмы, замеры, границы,
  вердикты стражей) — в CLAUDE.md и [`docs/`](../).
- **Формат записи:** `итерация — заголовок` · дата merge · PR · короткий коммит.
- **Нумерация итераций не всегда совпадает с порядком слияния** (в инфра/бэкенд-фазе
  часть итераций делалась вне числового порядка) — записи идут по фактической дате merge.
- Даты — по merge в `main`. Модуль `arena`, Go 1.25+, авторитетный сервер на Go +
  браузерный canvas-клиент.

Тэги/releases семвером пока не выпускались; версионирование — по итерациям.

## Фаза 1 — ядро неткода (итерации 1–11)

Фундамент: авторитетная симуляция, бинарный протокол, клиентское предсказание,
бой, компенсация задержки, масштаб и детерминизм как инструмент. `2026-07-24 … 07-27`.

- **Каркас (итерация 1)** · 2026-07-24 · `7e0aae2`…`0187df2` — модуль `arena`,
  `protocol` (типы+JSON-кодек v1, позже удалён), `transport` (интерфейс `Conn` + WS +
  in-memory `Pipe`), `game` (комната/мир/симуляция/часы/сессии), `hub`, `metrics`,
  `bot`, `cmd/server` (WS-gateway, конфиг из env, graceful shutdown), canvas-клиент.
- **Интерполяция (итерация 2)** · 2026-07-24 · `7f74625`…`729d502` — снапшоты 20 Гц из
  тика 30 Гц (делитель по Брезенхэму), интерполяция на клиенте, рендер на 100 мс в прошлом.
- **Бинарный протокол (итерация 3)** · 2026-07-24 · `b059df8`…`dc6186f` — JSON удалён,
  zero-alloc бинарный кодек (little-endian), клиент на ArrayBuffer/DataView.
- **Предсказание и реконсиляция (итерация 4)** · 2026-07-25 · `8058f81`…`65476c9` —
  очередь вводов игрока с дренажом за тик; клиент применяет свой ввод немедленно и
  переигрывает неподтверждённое поверх авторитетной позиции.
- **Бой + lag compensation (итерация 5)** · 2026-07-25 · `11eeb08`…`9b9393f` — стрельба,
  снаряды-сущности, урон, смерть/респаун, reliable-события Hit/Death/Spawn; перемотка
  целей по кольцу истории позиций (`ViewTick`), кламп окна как анти-чит.
- **Масштаб (итерация 6)** · 2026-07-25 … 07-26 · `02d3a56`…`fda1c13` — interest
  management (сетка AOI, `ARENA_AOI_RADIUS`), дельта-кодирование снапшотов против ack-базы
  клиента, пул буферов снапшотов, нагрузочный прогон `cmd/loadtest` (200 ботов, tick p99 ≈ 2.5 мс).
- **Реплеи (итерация 7)** · 2026-07-26 · `0bcb0a7`…`feea6b2` — лог seed+вводов во `World`,
  движок `Replay` со сверкой `Checksum`, `cmd/replay`, фаззер декодера лога.
- **Широкофазная коллизия (итерация 8)** · 2026-07-26 · `8085af5`…`f0d135e` — сим-сетка
  живых игроков (`hitGrid`), снаряд запрашивает лишь клетки вокруг сегмента; ~31–38× быстрее,
  безусловное совпадение с брутфорсом.
- **Field-level дельта (итерация 9)** · 2026-07-27 · `71f42a2`…`d48f9a8` — изменившаяся
  сущность несёт лишь реально изменившиеся поля под 1-байтной маской.
- **Статичные стены (итерация 10)** · 2026-07-27 · `ab65baa`…`3bdc2c4` — коллизия
  круг×AABB (игрок) и отрезок×AABB (снаряд), зеркалится в клиенте для предсказания.
- **Транспорт WebRTC DataChannel (итерация 11)** · 2026-07-27 · `54c64e0`…`8aa5f71` —
  вторая реализация `transport.Conn` поверх WebRTC рядом с WS, без переписывания игры.
